## 📌 Descripción del Proyecto

Este proyecto implementa la interfaz gráfica de usuario (GUI) utilizando **Python (Tkinter)** para resolver los 5 ejercicios resueltos del **Capítulo 6 (Genericidad, Excepciones y Archivos)** del libro de ejercicios de Leonardo Bermón Angarita.

---

## 📁 Estructura de Archivos

- `main.py`: Menú principal interactivo que despliega las ventanas de cada ejercicio.
- `ejercicio6_4.py`: Ejercicio 6.4 — Manejo de Excepciones en Cuenta Bancaria (`try-except`, `ValueError`).
- `ejercicio6_5.py`: Ejercicio 6.5 — Lanzamiento explícito de Excepciones (`raise`).
- `ejercicio6_6.py`: Ejercicio 6.6 — Captura de múltiples excepciones (`ValueError`, `ArithmeticError`).
- `ejercicio6_7.py`: Ejercicio 6.7 — Validación de campos de formulario.
- `ejercicio6_8.py`: Ejercicio 6.8 — Lectura de archivos de texto con gestión de errores de E/S (`IOError`, `FileNotFoundError`).
